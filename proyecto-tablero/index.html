Instrucciones

Cómo jugar

  1. El tablero contiene tres tipos de fichas mezcladas.
  2. Arrastra una ficha y suéltala sobre otra para intercambiar sus posiciones.
  3. También puedes pulsar una ficha y después otra para intercambiarlas.
  4. Ganas cuando todas las fichas de cada fila son del mismo tipo.
  5. Cambiar cualquier ajuste crea automáticamente una partida nueva.

Todas las partidas se generan con la cantidad exacta de fichas necesaria para que exista al menos una solución.
